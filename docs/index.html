Free browser extension & userscript

Delete X DMs in bulk.
Not one at a time.

X (formerly Twitter) only lets you delete DMs one by one. DM Bulk Delete adds a small panel to x.com/i/chat: tick whole conversations or single messages, confirm twice, and it works through X’s own delete menus for you — entirely inside your browser.

01 — Select

Two modes. One panel.

Clear whole conversations out of your inbox, or prune single messages inside a chat. Either way, you tick exactly what should go — then choose how it goes.

Conversations

  • Works in your inbox and in Message requests.
  • Click to tick, Shift-click to tick a range — or use Select all shown, or Load all & select to scroll through the entire list for you.
  • Group chats are skipped unless you turn on Also delete group chats (leaves them): on X, deleting a group conversation means leaving the group.

Messages

  • Tick single messages in the open chat: click, or Shift-click for a range.
  • Use Select all shown, or Load all & select to pull in the chat’s full history first.
  • Limit Select all to the messages you sent, or to the ones you received.

How messages go

For me only
Removes messages from your side. Works on any message.
For everyone (else for me)
Your own messages go for everyone; the other person’s fall back to “for me”.
For everyone only (else skip)
Anything that can’t be deleted for everyone is left alone.

02 — Run

Careful by default.

A bulk delete should be easy to stop and easy to follow. Every run is confirmed twice, can be halted instantly, and reports exactly what happened.

  • Two-step confirm

    Nothing is deleted until you click the red delete button a second time.

  • Stop at any moment

    An overlay blocks stray clicks while it works. Press Esc or click Stop to halt.

  • Sensible pacing

    800 ms between items by default, with random jitter. For big batches, don’t set it much lower, or X may rate-limit you.

  • Pauses when hidden

    Keep the tab in front. If it goes to the background or the window is covered, the run waits and carries on when you return.

  • Failures stay ticked

    Anything that fails is marked red and stays selected, ready to retry. Three failures in a row stop the run.

  • A clear record

    The panel counts what’s done, skipped and failed, and keeps a timestamped log of each item.

03 — How it works

It clicks what you would click.

X’s DMs now run on X Chat, which is end-to-end encrypted: every deletion has to be signed by your own client. There’s no API shortcut — so the extension works through X’s own menus in your browser, one item at a time, exactly as you would by hand.

For each message

  1. More
  2. Delete
  3. For me or For everyone

For each conversation

  1. Right-click
  2. Delete conversation
  3. Confirm

  • Built on X Chat’s own markers

    X Chat renders inside a shadow DOM. The element markers (such as data-testid) and button labels the extension looks for are taken from X Chat’s front-end code itself.

  • Reads 42 interface languages

    It recognises X Chat’s menu labels in all 42 of its interface languages, so it keeps working whichever one your X is set to.

  • Panel in English or Chinese

    The panel follows X’s interface language, falling back to your browser’s. Switch it any time under Language.

04 — Privacy

Nothing leaves your browser.

No server, no account, no analytics. Here is exactly what the extension and the userscript touch — straight from the privacy policy.

Read the privacy policy Audit the source

Runs on
Only x.com and twitter.com. The panel appears only on the messages page, x.com/i/chat.
Reads
The page’s internal IDs for your conversations and messages (conversation IDs are made of the participants’ numeric user IDs), where they sit on the page, and whether you sent each message — just enough to delete what you ticked. It doesn’t read or store message text.
Holds
That information stays in the page’s memory, is used only for the deletions you start, and is gone when you close or reload the tab.
Saves
Only your panel settings — delete mode, delay, panel position — in chrome.storage.local (localStorage for the userscript). Nothing is synced anywhere.
Sends
Nothing. No network requests, no analytics, ads or third-party services. Your data is never sent, sold or transferred — not to the author, not to anyone.
Permissions
storage, for those settings, and nothing else. Site access is limited to x.com and twitter.com.
Diagnostics
Copy diagnostics puts page-structure counts and the run log on your clipboard, with IDs cut to their last few characters and no message content. Whether to share it is up to you.
This site
No cookies, analytics, third-party scripts or web fonts; everything on this page is served from its own host, GitHub Pages, which keeps its own server logs.

Read this before you start

Deleting is permanent.
Back up first.

  1. There’s no undo

    Deleted messages and conversations can’t be brought back. The extension makes no backups and keeps no copy of anything it removes.

  2. Save what matters first

    If you might need something later, save it before a bulk run — for example, request your X data archive under Settings → Your account → Download an archive of your data, and check that it contains what you need.

  3. Others keep their copies

    “For me” deletions and deleted conversations only leave your account; the other people still see them. “For everyone” only works on messages you sent (group admins can also remove others’ messages in groups they manage).

DM Bulk Delete is an independent tool provided as is, under the MIT License. It isn’t an X product, and X can change its interface at any time.

06 — Use

Four steps, then let it run.

  1. Open your messages

    Go to x.com/i/chat. The DM Bulk Delete panel appears at the top right.

  2. Pick a mode

    Choose Conversations or Messages, then click Start selecting.

  3. Tick what goes

    Click rows to tick them, Shift-click for a range, or use Select all shown or Load all & select.

  4. Delete, then confirm

    Click the red delete button, then click it again to confirm. Keep the tab in front until it’s done; Esc stops it.

07 — FAQ

Questions, answered.

Something else? Ask on GitHub Issues.

Is this made by X?

No. DM Bulk Delete is an independent open-source project. It isn’t affiliated with or endorsed by X Corp., and “X” is a trademark of X Corp.

Can I undo a deletion?

No. The extension can’t restore anything it has deleted, and it keeps no copy. Save whatever you want to keep before you start — see Read this before you start.

Will the other person still see the messages?

If you delete “for me”, or delete a whole conversation, yes — it disappears only from your account. “For everyone” removes messages you sent for everyone in the chat; X doesn’t let you delete other people’s messages for everyone, except group admins in groups they manage.

What happens to group chats?

On X, deleting a group conversation means leaving the group. So group chats are skipped unless you tick Also delete group chats (leaves them) in the panel.

Does it work on message requests?

Yes. Conversations mode works in the Message requests list as well as in your inbox.

Why does the tab need to stay in front?

It works through X’s real interface, which has to be on screen. If the tab goes to the background or the window is covered, the run pauses and continues when you come back.

Can I make it go faster?

You can change Delay per item in the panel; the default is 800 ms with random jitter. For large batches, keep it at the default or higher so X doesn’t start rate-limiting you.

It stopped working after an X update. What now?

X changes its interface from time to time. Click Copy diagnostics at the bottom of the panel and paste it into a new GitHub issue. It contains only page-structure counts and the log — no message content.

Which languages does it support?

The panel is in English or Chinese. It follows X’s interface language (or your browser’s) and can be switched under Language. Behind the scenes, it recognises X Chat’s menu labels in all 42 interface languages.

Does it cost anything?

No. It’s free and open source under the MIT License.
